Подключение Google Таблиц

К мероприятиям

Один сервисный аккаунт можно использовать для всех мероприятий. Чтение публичного XLSX доступно без ключа; для чтения через API и отправки изменений нужен ключ и доступ к файлу.

  1. Откройте Google Cloud Console и выберите или создайте проект.
  2. В разделе «API и сервисы → Библиотека» включите Google Sheets API.
  3. Откройте «IAM и администрирование → Сервисные аккаунты», создайте аккаунт. Дополнительные роли проекта для доступа к таблице не нужны.
  4. В аккаунте откройте «Ключи → Добавить ключ → Создать ключ → JSON». Загрузите полученный файл ниже.
  5. Скопируйте email подключённого аккаунта и в нужной Google Таблице через «Настройки доступа» добавьте его как редактора.
  6. В мероприятии нажмите «Связать таблицу», вставьте ссылку, затем «Отправить в Google» для первого сохранения плана и служебных ID. После этого используйте кнопки обмена.
