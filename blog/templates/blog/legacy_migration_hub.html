Как идёт миграция

  1. База → люди. Загрузите файл базы (одна база — один год) и создайте анкеты. Один человек из разных баз — один аккаунт.
  2. Колонки → мероприятие. Отметьте колонки одного мероприятия, назовите его.
  3. ФиП. Прикрепите файл «Функции и позиции» — позиции и смены создадутся по наборам тим-лидеров. Без ФиП позиции создаются из значений.
  4. Сопоставление. Для каждого уникального значения ячеек выберите позицию и роль.
  5. Загрузка колонок. По одной или все готовые; повтор не создаёт дублей, изменённое сопоставление переносит участия.
