📌 Гайд по плейсхолдерам шаблона

В Word-файле шаблона используйте плейсхолдеры в фигурных скобках — при генерации они заменяются на данные волонтёра.

Поля волонтёра (в любом месте документа):
{full_name}ФИО волонтёра
{faculty}Факультет
{education_program}Образовательная программа (ОП)
{course}Текущий курс (считается из года поступления)
{graduation_year}Год выпуска
{admission_year}Год поступления
{date}Дата выдачи справки
{period}Охват (сезон / диапазон дат / всё время)
Пол волонтёра (подставляется по указанному в профиле полу — мужская/женская форма):
{student}студент / студентка
{participated}принял / приняла
{he_she}он / она
{his_her}его / её
{studying}обучающийся / обучающаяся
Блок перечисления мероприятий — всё между этими строками повторяется по каждому мероприятию: 
### START EVENTS ###
{n}. {title} — {dates}
Часы: {hours} · Масштаб: {scale}
Описание: {description}
### END EVENTS ###
Внутри блока: {n} (номер), {title}, {dates}, {format} (волонтёр/тим-лидер), {hours}, {scale}, {description}.
