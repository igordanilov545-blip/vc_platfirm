# `data_base/data_controller/` — единый слой доступа к данным

Единственная «прямая» точка входа к БД для бота и веб-аутентификации. Исторически был
одним файлом `data_controller.py`; теперь — пакет по доменам, но **публичный контракт
сохранён**: весь код по-прежнему делает `from data_base.data_controller import <функция>`
— имена реэкспортируются в [`__init__.py`](__init__.py).

## Что где лежит

| Модуль | Домен |
|---|---|
| [`_base.py`](_base.py) | Логгер канала `vc.db`, `actor`, generic-функции (`get_full_table`, `create_record_generic`), карта таблиц. |
| [`users.py`](users.py) | Пользователи; роли менеджер/тим-лидер; матчинг и дозаполнение профиля из прошлых заявок. |
| [`orgs.py`](orgs.py) | Организации, организаторы, их связи и взаимодействия, локации. |
| [`events.py`](events.py) | Мероприятия, смены, категории, staff, публикация, рассылка. |
| [`event_groups.py`](event_groups.py) | Новый верхний уровень мероприятий: queryset, сохранение названия и менеджеров. Прежние `events.py`/`Event` относятся к позициям. |
| [`applications.py`](applications.py) | Заявки, привязка смен, участия (явка), запросы фидбека. |
| [`requirements.py`](requirements.py) | Требования меро, их привязка, исключения по пользователям. |
| [`reference.py`](reference.py) | Фидбек, комментарии, история чарна, сезоны, константы. |
| [`achievements.py`](achievements.py) | Система достижений: справочник, выданные, агрегат-кэш держателей. |
| [`querysets.py`](querysets.py) | Ленивые `*_qs()` для отчётов + скаляры (`get_current_season`). |
| [`__init__.py`](__init__.py) | Фасад: реэкспорт всего публичного `__all__`. |

## Правила (как писать код здесь)

- **Только тонкий CRUD и простые фильтры.** Бизнес-логика (ACL, пересчёты, матчинг
  сложнее «найти по полю») — в `blog/services/*`, не тут (coding-principles §1).
- **Каждая ИЗМЕНЯЮЩАЯ функция логируется** в канал `vc.db` (→ `logs/db.log`): `INSERT`/
  `UPDATE`, с `actor` (кто) и субъектом (над кем). Чтения (`get_*`) не логируем.
- **Именование:** `create_* / get_* / update_* / mark_* / add_*` возвращают объект или
  `list`; `*_qs()` — **ленивый** queryset для композиции в отчётах (не материализуй его
  тут `.list()`-ом).
- **Новую операцию доступа к данным добавляй сюда как функцию**, в подходящий доменный
  модуль, и добавь её имя в `__all__` внутри `__init__.py` (иначе она не реэкспортится).
- Модели импортируем из `blog.models`; общий логгер — из `._base`.
