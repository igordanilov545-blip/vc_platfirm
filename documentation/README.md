# Документация платформы Волонтёрского центра

Индекс проектной документации. Начни с ⭐-помеченных, если ты в проекте впервые.

## Как устроен проект

| Документ | О чём |
|---|---|
| ⭐ [coding-principles.md](coding-principles.md) | **Принципы работы с кодом**: слоистость, единый слой БД, аутентификация, ACL, доменные инварианты, стиль. Главный ориентир при разработке. |
| [architecture.md](architecture.md) | Архитектура и взаимодействие компонентов. Начинается с раздела **«Реализация vs. план»** — что реально в коде, а что целевой дизайн. |
| [access-control.md](access-control.md) | Модель прав: роли (волонтёр / тим-лидер / менеджер), контекстные права ТЛ, ACL. |
| [db.md](db.md) | Схема БД и бизнес-правила (нумерованные правила 1–11, на которые ссылается код). |
| [logging.md](logging.md) | **Логирование**: три канала (web/bot/db), куда пишем, правила, эксплуатация. |
| [profiles.md](profiles.md) | Профиль пользователя, «заполненный аккаунт», префилл из TG/Excel. |
