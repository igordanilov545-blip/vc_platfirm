Функционал Telegram-бота Волонтёрского центра

Интерактивные деревья состояний бота по каждой роли. Узел — это экран бота (в нём лежит текст, который бот отвечает, и его кнопки-меню). Ребро — это действие пользователя (нажал кнопку / ввёл команду), ведущее в следующее состояние. Открой узел — увидишь полный ответ бота и все ветки, куда из него можно уйти. Это карта, по которой тим-лидер утверждает поведение бота.

действие — обычная ветка (нажал кнопку / команду)
предупреждение — ошибочный / пограничный исход
бот сам — проактивно, без действия пользователя
первое касание

Гость

/start, просмотр мероприятий без регистрации, попытка подать заявку → регистрация (имя + телефон), контекстная справка.

 базовое меню

Волонтёр

Мероприятия и подача заявок (в т.ч. повторная — посмотреть/изменить), мои заявки, статистика, подписка на новые меро, доступ к сайту, оценка после участия.

 свои меро (контекст)

Тим-лидер

Список своих меро, подробная карточка (контакты организатора, набор), обработка заявок (в т.ч. пачкой и при переборе), явка, «полная смена» ТЛ, тумблер уведомлений о заявках.

 все меро + публикация

Менеджер

Все заявки системы, контакты организаторов активных меро, публикация сформированного меро и рассылка по нему, тумблер уведомлений о заявках.

Как читать дерево

  • Узел = состояние/экран бота. Клик по узлу открывает панель: что отвечает бот (реплика + кнопки меню) и ветки — куда можно уйти дальше.
  • Ребро = действие пользователя, подпись на ребре — какую кнопку он нажал / что ввёл. Клик по ребру подсвечивает ветку у родительского состояния.
  • Внутри панели ветки кликабельны — переходишь к следующему состоянию, не теряя нить.
  • Тяни мышью — панорама · колесо / кнопки — зум · «Вписать» — общий вид. Точки зафиксированы, интернет не нужен.

Роли аддитивны

  1. Гость — есть запись в users, регистрация не завершена. Только просмотр меро.
  2. Волонтёр — регистрация завершена. Полное базовое меню.
  3. Тим-лидер — видит всё меню волонтёра + функции по своим меро. Чужие меро видит как обычный волонтёр.
  4. Менеджер — всё вышестоящее + все заявки, контакты организаторов, публикация и рассылка.
