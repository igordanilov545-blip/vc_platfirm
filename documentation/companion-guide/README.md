# Компаньон-гид по платформе

> Сценарии интерактивного «компаньона» (онбординг-тура), который объясняет функционал
> при первом входе на веб-платформу и при повторном запуске гайда из настроек (позже).
> Источник экранов и якорей — **реальный код** (`blog/templates/blog/base.html`,
> `blog/urls.py`, шаблоны). CJM (`documentation/cjm/`) взят как источник эмоций и «вау»-акцентов.

---

## 0. Принцип наследования (главное)

Гайд **не дублируется** между ролями. Он собирается наследованием:

```
Волонтёр           = [volunteer]
Тим-лидер          = [volunteer] + [заглушка-ТЛ] + [team-leader]
Менеджер           = [volunteer] + [заглушка-ТЛ] + [team-leader] + [заглушка-МН] + [manager]
```

- **`volunteer.md`** — базовый путь. Его проходят все три роли.
- **`team-leader.md`** — только то, что добавляет тим-лидер. В начале — «кадровая заглушка»
  (`handoff_tl`): переход-мостик «а теперь то, что умеет тим-лидер».
- **`manager.md`** — только то, что добавляет менеджер. В начале — заглушка `handoff_mgr`.

Так одно и то же место (напр. «Мероприятия») описано **ровно один раз** — в `volunteer.md`.
Меняешь текст там — он меняется у всех трёх ролей автоматически.

Движок компаньона склеивает массив шагов роли из этих файлов в порядке выше.

**Реализация движка:** `blog/static/blog/js/companion.js` (`window.CompanionTour`) — универсальный
пошаговый тур со spotlight-вырезом и карточкой гуся (см. agent-workflow.md §4). Первый
подключённый сценарий — тур по настройкам (`settings.html`): гусь ведёт по вкладкам-разделам,
переключая панель сверху. Фото компаньона — `blog/static/blog/companion/goose_0..3.jpg`
(4 закреплённых слота, сейчас все указывают на один файл — менять точечно). Остальные секции
гайда (`volunteer.md`/`team-leader.md`) в UI пока не подключены — следующий шаг.

## 1. Формат шага

Каждый шаг — блок вида:

```
### <id> · <короткое имя>
- **Якорь:** css-селектор или data-track элемента, к которому крепится подсказка
- **Позиция:** right | left | bottom | top | center (модалка по центру экрана)
- **Условие:** когда шаг показывается (always / is_manager / профиль пуст / …)
- **Текст:** сама фраза (≤ 20–25 слов, кроме функциональных блоков ТЛ/МН)
```

**Якоря** берутся из реального DOM. Самые надёжные — атрибуты `data-track` в сайдбаре
(`nav:dashboard`, `nav:event_list`, `nav:pending_applications`, `nav:user_list`,
`nav:report_period`, `nav:dobro_page`, `nav:analytics_dashboard`) и тексты кнопок.
Где точного якоря нет — указан текст-ориентир кнопки/ссылки.

---

## 2. Тон

- Коротко и на «ты». Пользователь не читает простыни: если фраза длиннее ~25 слов — режем.
- Исключение: тяжёлые функциональные блоки у ТЛ и менеджера — им можно чуть больше.
- Пара мемов/отсылок допустима (помечены 🎬), но по одной на секцию, не спамим.

---

## 3. Файлы

| Файл | Кого касается | Что содержит |
|---|---|---|
| `volunteer.md` | все | первый вход, профиль, мероприятия, заявка, статистика, ПГАС, вход без ВПН |
| `team-leader.md` | ТЛ + МН | заглушка + мои меро, заявки, явка, часы, профиль волонтёра, лента |
| `manager.md` | МН | заглушка + создание меро, публикация/рассылка, импорт, справочники, роли, отчёты, настройки |
