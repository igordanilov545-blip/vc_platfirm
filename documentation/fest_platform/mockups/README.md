# Demo-макеты Fest (статичные HTML)

Кликабельный прототип для презентации. Открывать двойным кликом в браузере — всё
самодостаточно (CSS/JS встроены, никаких зависимостей). Между страницами есть
навигация; кнопки действий — заглушки (попап «Скоро»).

| Файл | Экран | Что показывает |
|---|---|---|
| [overview.html](overview.html) | **Обзор для ЛПР** (точка входа) | Одностраничник ~на 1 минуту: сверху килл-фичи и закрываемые боли, ниже подробности по мини-вкладкам (фест / маркет / кабинет гостя / кабинет организатора / бот) и блок «что платформа может дать» (качественно, без выдуманных цифр). |
| [fest.html](fest.html) | **Страница феста** (главный вау-экран) | Hero + живой countdown, о фесте, программа по сценам, гости, тарифная сетка билетов, локация, галерея, FAQ, партнёры. Кнопка «Купить» → «Скоро». |
| [market.html](market.html) | **Маркет** | Витрина продавцов и товаров, фильтры-чипы, чип кошелька. «Предзаказать» → попап списания с кошелька (заглушка). |
| [cabinet.html](cabinet.html) | **Личный кабинет гостя** | Переработан по CJM (см. ниже): умная шапка (кто я + KPI), большая карточка ближайшего феста с **билетом-QR на первом экране** (открывается офлайн), быстрые действия, трекер предзаказов со статусом и точкой выдачи, витрина «я — постоянный» (статус/прогресс/челлендж/бейджи), приглашения. Вкладки — вторичны. |
| [organizer.html](organizer.html) | **Кабинет организатора** | Сайдбар управления, плитки KPI, график продаж по дням, донат по тарифам, таблица покупателей. Кнопки «Добавить/Аналитика/Рассылка» → «Скоро». |

Рекомендуемый порядок показа: **overview → fest → market → cabinet → organizer**.
Для ЛПР начинать с [overview.html](overview.html).

Айдентика/контент — плейсхолдерные (эмодзи вместо фото). Тема тёмная, гиковая; под
реальный бренд заказчика цвета/лого/фото подставляются позже.

## CJM гостя (обоснование дизайна ЛК)

ЛК гостя переработан не «на глаз», а по карте пути: [../cjm/guest.html](../cjm/guest.html)
(двойной клик по узлам — экран, эмоция, wow-фикс). Ключевые выводы, легшие в дизайн:

- **Билет — на первом экране, офлайн.** Самый частый и самый стрессовый мотив входа
  (у турникета, слабая сеть) → билет-QR ближайшего феста вынесен в hero, не прячется
  за вкладками.
- **Карточка «Мой ближайший фест»** отвечает на «что / где / когда / что мне положено»
  одним взглядом (отсчёт, место, мой тариф с перками, кнопки Билет / Программа / Как
  добраться).
- **Предзаказы — трекер со статусом и точкой выдачи**, а не просто списание — снимает
  тревогу «заберу ли я оплаченное».
- **Витрина «я — постоянный»** (статус, прогресс до уровня, челлендж сезона, бейджи) —
  эмоция принадлежности и повод возвращаться.
