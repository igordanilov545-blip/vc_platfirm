# Ассеты Minecraft

Поставка из `brandbook_minecraft/minecraft_assets` подключена в
`blog/static/blog/appearances/minecraft/`. Все необходимые для текущего интерфейса
ассеты получены; дополнительных изображений сейчас не требуется.
Имена в таблице — точные имена файлов. Окружение — без текста и нарисованного UI;
передний план — PNG/WebP с прозрачностью и светом сверху слева.
Подробное художественное ТЗ: [брендбук](brandbook_minecraft/asset-manifest.md).

| Название ассета | Что изображено | Где используется |
|---|---|---|
| `world-light.webp` | Дневной блочный лес, дальние холмы, тёплый свет; 2560×1440 | Фон светлой темы |
| `world-dark.webp` | Ночной блочный мир, обсидиан, мягкий фиолетовый свет; 2560×1440 | Фон тёмной темы |
| `foreground-light.webp` | Дерево и каменный уступ, свет слева, прозрачный фон; 600×1200 | Передний план светлой оболочки |
| `foreground-dark.webp` | Обсидиановый уступ с кристаллом и редстоуном, прозрачный фон; 600×1200 | Передний план тёмной оболочки |
| `hero-light.webp` | Волонтёрская команда у старта в блочном лесу, без надписей; 1400×600 | Баннер главной, светлая тема |
| `hero-dark.webp` | Та же команда вечером, фонари и фиолетовые отблески; 1400×600 | Баннер главной, тёмная тема |
| `frames/limestone/9slice.png` | Известняк, углы и повторяемые стороны | Светлые карточки |
| `frames/masonry/9slice.png` | Толстая каменная кладка | Статистика |
| `frames/timber/9slice.png` | Деревянные брусья и соединения | Панели профиля |
| `frames/obsidian/9slice.png` | Обсидиан с холодными сколами | Ночные карточки |
| `frames/mossy/9slice.png` | Кладка с локальным мхом | Приоритетный показатель |
| `frames/ember/9slice.png` | Угольный камень с тёплыми гранями | Ночная статистика |
| `moss-corner.webp` | Неровная колония мха с короткой тенью, прозрачный фон; 300×180 | Один угол приоритетной карточки |
| `lantern.webp` | Подвесной блочный фонарь на кронштейне, прозрачный фон; 220×400 | Стык навигации и полотна |
| `lantern-glow.webp` | Свечение по силуэту фонаря | Локальное освещение |
| `foreground-dark-glow.webp` | Свечение редстоуна по силуэту камня | Ночной передний план |

Рамки — атласы 768×768, срез 128, `repeat`. Прямоугольные превью и цельные квадратные
рамки остаются в исходной поставке; в интерфейсе не растягиваются. Отдельные файлы
углов и сторон также сохранены в брендбуке: рабочий атлас содержит те же части,
поэтому копировать их повторно в статику не требуется.
После обновления изображений: `python manage.py collectstatic --noinput` и перезапуск.
